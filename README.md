# Interactive Date Agreement ❤️

Премиальное мобильное веб-приложение, которое красиво приглашает на свидание: милые вопросы, убегающая кнопка «НЕТ», конфетти, выбор места, даты и времени, официальное «соглашение» с подписью пальцем и финальный сертификат.

Работает **полностью в браузере** — без сервера, без базы данных, без API. Все данные живут только в памяти страницы. Можно бесплатно разместить на **GitHub Pages** и отправить ссылку.

---

## ✨ Что внутри

- Анимированное приветствие
- Милые вопросы (любой ответ ведёт дальше)
- Главный вопрос с кнопкой «НЕТ», которая убегает, уменьшается и исчезает 😅
- Сердечки, конфетти и вибрация после «ДА»
- Выбор места карточками
- Выбор даты и времени (родные пикеры телефона)
- Официальное соглашение с подписью пальцем (HTML Canvas) и красной печатью «ОДОБРЕНО»
- Финальный сертификат с подписью
- Glassmorphism, плавные переходы, floating hearts, современная типографика
- Работает офлайн после первой загрузки (PWA), можно «установить» на телефон

---

## 🛠 Технологии

React 18 + Vite 5, framer-motion (анимации), canvas-confetti (конфетти), самостоятельно встроенные шрифты (офлайн), PWA.

## ✏️ Как изменить текст и имена

Весь текст, имена, вопросы и список мест — в одном файле:

```
src/data/config.js
```

Открой его и поменяй значения. Например, имена:

```js
her: 'Юлдуз',   // кого приглашают
him: 'Бехруз',  // кто приглашает
```

Список мест — просто массив, добавляй/убирай строки:

```js
places: [
  { label: 'Кофейня', icon: '☕️' },
  { label: 'Ресторан', icon: '🍽️' },
  // ...добавь своё
],
```

Эмодзи можно вставлять прямо в текст.

## 💻 Как запустить локально

Нужен установленный [Node.js](https://nodejs.org/) (версия 18 или новее).

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить режим разработки:

   ```bash
   npm run dev
   ```

3. Открыть в браузере адрес, который покажет терминал (обычно `http://localhost:5173/date-agreement/`).

> Чтобы проверить на телефоне в той же Wi-Fi сети, запусти `npm run dev -- --host` и открой на телефоне адрес вида `http://192.168.x.x:5173/date-agreement/`.

Собрать готовую версию и посмотреть её локально:

```bash
npm run build      # собирает в папку dist/
npm run preview    # запускает локальный предпросмотр готовой сборки
```

## 🚀 Как бесплатно опубликовать на GitHub Pages

Итоговая ссылка будет вида:

```
https://ВАШ_ЛОГИН.github.io/date-agreement
```

> ⚠️ **Важно про название репозитория.** Адрес собирается из имени репозитория. По умолчанию проект настроен на репозиторий с именем **`date-agreement`** (см. `REPO_NAME` в `vite.config.js`).
> - Если назовёте репозиторий иначе — поменяйте `REPO_NAME` в `vite.config.js` на это же имя.
> - Имя должно совпадать буква-в-букву, иначе стили и скрипты не загрузятся.

### Способ 1 — автоматически через GitHub Actions (рекомендуется)

Сборка происходит на стороне GitHub — вам **не нужно** ничего собирать у себя. В проекте уже есть готовый workflow (`.github/workflows/deploy.yml`).

1. Создайте на GitHub новый **пустой** репозиторий с именем `date-agreement`.

2. Загрузите проект в него (из папки проекта):

   ```bash
   git init
   git add .
   git commit -m "Date agreement app"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/date-agreement.git
   git push -u origin main
   ```

3. На GitHub откройте репозиторий → **Settings** → **Pages** → в разделе **Build and deployment** в поле **Source** выберите **GitHub Actions**.

4. Готово. После каждого `git push` в ветку `main` сайт пересобирается и публикуется автоматически. Прогресс виден во вкладке **Actions**. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/date-agreement`.

### Способ 2 — вручную одной командой (gh-pages)

Этот способ собирает проект у вас на компьютере и публикует папку `dist` в ветку `gh-pages`.

1. Загрузите проект в репозиторий `date-agreement` (как в шагах 1–2 выше).

2. Выполните:

   ```bash
   npm install
   npm run deploy
   ```

   Команда соберёт проект и отправит его в ветку `gh-pages`.

3. На GitHub: **Settings** → **Pages** → **Source** → выберите ветку **`gh-pages`**, папка **`/ (root)`**, сохраните.

4. Через минуту сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/date-agreement`.

## ❓ Если что-то не загрузилось

- **Белая страница / нет стилей.** Имя репозитория не совпадает с `REPO_NAME` в `vite.config.js`. Сделайте их одинаковыми и опубликуйте заново.
- **Сайт не появился сразу.** GitHub Pages может обновляться 1–2 минуты. Обновите страницу.
- **Старая версия в браузере.** Это PWA с офлайн-кэшем — обновите страницу или откройте в режиме инкогнито.
